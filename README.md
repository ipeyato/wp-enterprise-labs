# WordPress Enterprise Labs

Hands-on labs for enterprise WordPress development, following the
[WordPress VIP Learn](https://learn.wpvip.com) course
**Development, Build, Test, and Deployment**.

Each lab lives in its own folder under `labs/` and runs locally.

## Labs

| # | Lab | Topics |
|---|-----|--------|
| 01 | [Development environment standardization](labs/01-dev-environment/) | wp-env, environment types, secrets, version pinning |

## Notes

My study notes (in Bahasa Indonesia) are in [`notes/`](notes/): lesson summaries and quick references.

## Requirements

- PHP 8.2+
- Composer 2
- Node.js 20+
- Docker (for local WordPress environments)

## Conventions

- One lab per folder: `labs/NN-short-name/`
- Every lab has its own `README.md`: goal, how to run it, what I learned
- Code follows the [WordPress VIP coding standards](https://github.com/Automattic/VIP-Coding-Standards)
